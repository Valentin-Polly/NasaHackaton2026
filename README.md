# NasaHackaton2026
Carpeta Lunaris: Contiene backend y frontend de la aplicacion desarrollada
Carpeta Backend: Contiene archivos con informacion publica de la nasa utilizada para realizar el proyecto, y programas en python para filtrar la informacion correctamente en un .json
Carpeta FrontEnd: Desarrollo Web de la aplicacion. Para ejecutar la aplicacion en la terminal Primera Opcion: 1º npm install 2º npm run dev 3º Copiar el link https resultante en el navegador web de preferiencia.
