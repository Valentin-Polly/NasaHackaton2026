# 🌙 Lunaris

**Lunar Landing Site Navigator** · NASA Space Apps Challenge 2026 · Team *famaf.exe* · Córdoba, Argentina

[🇬🇧 English](#-english) · [🇦🇷 Español](#-español)

---

## 🇬🇧 English

Lunaris is an interactive 3D Moon simulator built with real NASA data. Explore lunar South Pole landing sites and relive the six Apollo landings through photo markers and curious facts.

### 📁 Project structure

| Folder | Contents |
| --- | --- |
| `Lunaris/` | The full application (backend and frontend). |
| `Lunaris/backend/` | Public NASA data used for the project, plus Python scripts that filter it into a `.json` file. |
| `Lunaris/frontend/` | The web application (React, Three.js, Vite). |

### 🚀 How to run it

**🪟 Windows: portable executable**

Download **[Lunaris Portable EXE](https://drive.google.com/file/d/1kOs60uMXSDLYM6Q9trspK_Qp3EXTfgqH/view)** and run it. No installation needed.

**🐧 Linux / any system: web version**

1. Go to the frontend folder:
   ```bash
   cd Lunaris/frontend
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
4. Open the local address shown in the terminal (usually `http://localhost:5173`).
